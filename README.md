# WeIntern Week 2 — Project 3: AI Content Generator

## What this starter includes
- Blog Post, Social Media Caption, and Text Summary modes
- Topic, tone, and target-length inputs
- Empty-topic validation
- Regenerate/refine button
- Word and character counts
- Download generated draft as a text file
- Prompt-template preview

**Important:** This first checkpoint uses a transparent Python template, not a real language model. The next step will be to connect an AI backend so content becomes more natural and topic-specific.

## Requirements
- Python 3.10+
- Internet is needed to install Streamlit, but the app itself can run offline in starter mode.

## Run on Windows
1. Extract the ZIP.
2. Open the extracted folder in Command Prompt or VS Code terminal.
3. Install the dependency:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Start the app:
   ```bash
   python -m streamlit run app.py
   ```
5. A browser tab should open automatically.
